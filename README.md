# Lexi · 划词词典与复习

一个无构建依赖的油猴脚本：划英文单词查释义、音标和发音，保存跨网站历史，把收藏词加入间隔复习。

初始设计在 [docs/INITIAL_DESIGN.md](docs/INITIAL_DESIGN.md)。按照已确认的选择，数据使用 **油猴 GM 本地存储**，不同网站共享同一份词库，未使用页面 localStorage。

## 安装

1. 在桌面浏览器安装并启用 Tampermonkey。
2. 新建用户脚本，将 [lexi.user.js](lexi.user.js) 全文粘贴进去，保存并启用。
3. 刷新普通 HTTP/HTTPS 网页，选中一个英文单词；右下角 **L** 可打开学习中心。

如果浏览器要求用户脚本权限，按 Tampermonkey 和浏览器的提示启用。浏览器内部页面、扩展商店、PDF 阅读器等受限页面不在适用范围。首版只处理顶层普通网页，不读取跨域 iframe。

## 使用

学习中心的 Lexi 标识旁显示当前安装的脚本版本，窄屏同样可见。

0.2.1 新增“查词直接进入生词本”设置（默认关闭），并将历史与生词本页的收藏按钮移至列表。

0.2.2 优先使用并缓存有道音标，保留主词典音标作为备用，并将播放按钮移至音标旁。

0.2.3 简化播放图标，移除边框和背景，并增加按下时缩小、变色和透明度反馈。

0.3.0 按 Anki 实践优化复习：学习步骤在同一轮内完成，学习日从凌晨 4:00 开始，每日新词上限，积压时优先复习最可能遗忘的词，记录逐次复习并显示真实记得率与难记词，原句语境、快捷键与撤销，可调目标记得率和可选反向卡。任务清单见 [复习优化任务](docs/REVIEW_OPTIMIZATION_TASKS.md)。

- **查词**：选择单个英文词自动查询，也可在学习中心输入。支持 `don't`、`mother-in-law`，不支持整句翻译。需要音频时点击播放。
- **音标**：优先使用有道词典音标，先英式、其次美式，成功后缓存并标注来源；更新英文释义时保留已缓存的有道音标。旧历史、生词本和复习页打开时同样获取，无需重新查词，也不会增加查询历史。请求期间或失败时保留主词典音标，失败会显示状态并可重试。播放按钮紧贴音标，点击播放单词发音。
- **历史**：每次成功查询都保存，包括重复查询和缓存命中；支持最早/最近排序和按词过滤。悬停或用键盘聚焦记录时显示删除按钮，只删除这一次查询，词条缓存、收藏和复习进度保留。打开历史详情不会增加记录。
- **中文释义**：查词或打开词条后，自动翻译最多 6 条英文释义，按词性和编号显示；成功后保存到油猴本地词库，再次打开直接读取。已有单条翻译会自动补全。服务可能限流或不可达，失败时可重试。
- **收藏**：只有生词本中的词进入复习。可在查词卡、查词历史列表或生词本列表中直接切换收藏状态；也可在设置中开启“查词直接进入生词本”。取消收藏会删除该词复习进度，查询历史保留。
- **复习**：参考 Anki，先回忆、再显示释义，选择“忘记／困难／记得／轻松”（快捷键 1–4，空格显示答案，R 发音，Ctrl/⌘+Z 撤销）。使用内嵌的 TS-FSRS 5.4.2（FSRS-6）按每个词的记忆稳定性、难度、实际间隔和反馈计算下次时间，按钮预览的间隔即保存的间隔。“记得”和“轻松”都不会让单词永久退出复习，最长间隔为 365 天。新词使用 1 分钟／10 分钟学习步骤，已学词忘记后进入 10 分钟重学；这些短步骤在同一轮内回到队列完成。每轮最多 20 张，依次为学习中、到期复习、新词；新词默认每天 20 个。积压时优先复习最可能遗忘的词，可继续下一轮；逾期任务保留。保存过阅读上下文的词会在卡片上显示原句，缺少中文释义时在背面自动补全。
- **复习安排**：学习日从凌晨 4:00 开始，长期复习从到期日 4:00 起可复习。概览显示到期复习、今日新词、今天复习过的不同词数、收藏词数、近 30 天真实记得率、难记词（遗忘 ≥ 8 次）和最近 6 个后续安排。没有到期卡片时显示下次复习时间，页面保持打开会自动更新到期状态；生词本可查看每个词的完整安排。只在打开学习中心时查看，不主动弹出系统通知。
- **设置**：可以暂停自动划词、开启“查词直接进入生词本”，或开启本地阅读上下文记录；复习可调每日新词上限（0–200）、目标记得率（85%–95%，默认 90%），并可开启反向卡（看中文想英文，可选拼写核对，进度独立）。外观自动跟随系统深浅色。

历史列表一次显示前 300 条匹配记录；筛选可缩小范围，导出包含全量历史。存储不会按 300 条截断。

历史和生词本的列表、释义区域独立滚动；查词卡、设置和复习等区域共用细窄、透明轨道的滚动条，颜色跟随深浅主题。鼠标位于学习中心或查词卡内时，滚轮不会带动背景网页，Ctrl＋滚轮仍可缩放。

## 备份

学习中心 → 设置：

- **导出 JSON 备份**：词条、完整查询历史、生词复习进度（含 FSRS 记忆状态、逐次复习记录和反向卡进度）及设置。0.3.0 使用备份格式 v3，支持导入旧 v1／v2 备份；新备份需要 0.3.0 或更新版本恢复。
- **导入 JSON 合并**：预览数量后确认，按事件 ID 去重、按时间保留更新的词条和进度；两台设备分别复习过同一个词时，合并两端复习记录并重放计算进度。保留当前设置。最大 5 MiB；最多 10,000 个词条、30,000 次查询、10,000 个生词进度。超过该规模仍可导出，首版导入需扩容后处理。
- **导出历史 CSV / 生词 CSV**：UTF-8 BOM，方便表格查看；不能用于完整恢复。

数据不会自动跨浏览器或设备同步。卸载扩展或清理扩展数据前应导出 JSON。导入不是跨记录事务；写入被中断时会提示，重新导入可继续合并。并行查询的历史分别保存，相同词的并行修改以最后一次写入为准。

升级不重排旧词的到期时间，也不清空累计次数。旧版没有完整逐次反馈，首次迁移以旧间隔估计稳定性，并从默认难度开始，之后由真实复习反馈继续更新。算法、迁移边界及参考资料见 [复习设计](docs/REVIEW_DESIGN.md)；面向使用者的完整规则可在浏览器打开 [复习规则（HTML）](docs/REVIEW_RULES.html)。

## 服务与隐私

- 主词典：[Free Dictionary API](https://dictionaryapi.dev/)，提供英文释义、音标、例句和音频；并非每个词都有全部字段。
- 首选音标：[有道词典](https://www.youdao.com/)，没有已缓存的有道音标时发送当前单词，保存返回的音标；不改用有道的释义或音频。
- 中文辅助：[MyMemory](https://mymemory.translated.net/doc/spec.php)，请求最多 6 条词典释义，每段最多 480 UTF-8 字节；不是专业双语词典。
- 不包含账号、密钥、云同步、广告、分析上报或网页抓取。
- 第三方会看到查询词（获取首选音标时也发送给有道）及自动翻译的词典释义，以及正常网络连接信息。开启来源记录后，上下文保存在本地，不随查词请求发送。
- 只有点击才播放在线音频；缺失或失败时尝试系统英语朗读，朗读服务也可能联网。

```console

node tests/core.test.cjs
node tests/ui.test.cjs
```
