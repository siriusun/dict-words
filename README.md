# Lexi · 划词词典与复习

一款运行在 Tampermonkey 中的英文学习插件，将**网页划词、句子翻译、词汇收藏与间隔复习**串成完整的学习流程。

无需注册 Lexi 账号，学习数据默认保存在本机，不同网站共用同一份查词历史、生词本和复习进度。需要跨设备时，可选用坚果云手动同步。

## 安装

1. 在桌面浏览器或支持 Tampermonkey 的手机浏览器（如 Firefox for Android）中安装并启用 Tampermonkey。
2. 新建用户脚本，将 [lexi.user.js](lexi.user.js) 全文粘贴进去，保存并启用。
3. 刷新普通 HTTP/HTTPS 网页，选中英文单词即可查词，选中短语或句子即可翻译；手机选好后点底部「查词／翻译」操作条，其他触屏设备点浮动按钮，鼠标仍会自动显示结果。点击右下角 **L** 打开学习中心。

如浏览器提示用户脚本权限，请按提示启用。仅支持顶层普通网页，不在 iframe 中运行；浏览器内部页面、扩展商店、PDF 阅读器等受限页面不适用。
更新后首次使用微软备用翻译时，Tampermonkey 可能提示允许访问 `edge.microsoft.com`。

## 功能与特色

### 划词即查，中英对照

- **网页划词与手动查询**：单个英文词按原有方式查词，支持外围标点、`don't`、`mother-in-law` 等形式；包含两个以上英文词的短语或句子翻译为简体中文，无须句号。鼠标选中后自动查询；触屏选中后显示「查词／翻译」入口，可先拖动系统选区手柄扩选，再按最新选区执行。手机底部操作条会预览选中内容；点击入口后清除原生选区，通常会收起系统菜单，并保留原文定位标记。需要重新使用系统菜单时，可再次选中文字。桌面和触屏都可在学习中心搜索框输入单词或句子。
- **一次性句子翻译**：显示所选原文和中文译文，每次最多 5,000 个字符；较长文本会分段翻译。优先使用 Google Translate，开启备用翻译时失败后依次尝试 Microsoft Translator、MyMemory；失败可重试。原文和译文仅在当前结果中显示，不保存至历史、生词本、复习、缓存、备份或同步；关闭后清除。
- **英文释义与用法例句**：每组词性最多保留 20 条主词典释义及其对应例句；有道补充例句首次使用简要结果，点击「更新用法例句」从完整例句结果获取最多 12 条去重后的例句，展示英文、可用的中文译文与出处，高亮当前单词。补充例句不与释义逐条对应，不生成或推测场景；实际数量取决于词典返回内容，不保证每个含义都有例句。查词卡、历史、生词本与复习答案共用缓存；旧词条可点击「更新释义」重新获取各含义的例句，不影响收藏和复习进度。无例句或加载失败时明确提示并可重试。点击音标旁的播放按钮听单词发音。
- **双来源中文辅助**：同时展示 MyMemory 对英文释义的翻译与有道中文词典释义，分别加载、缓存和重试，一路失败不影响另一路。
- **机器翻译自动回落**：单词英文释义仍优先 MyMemory，失败时默认回落至 Google Translate；句子则按 Google Translate → Microsoft Translator → MyMemory 顺序尝试，并标注实际来源。单词释义保存缓存，句子翻译不缓存。可在设置 → 中文释义中关闭备用翻译，此时单词和句子都只使用各自的首选来源；已有单词缓存保留，也可手动重试 MyMemory。有道词典继续独立显示，不充当机器翻译。
- **词形变化**：展示原形、复数、时态等词形信息，查询变形词时可追溯原形，例如 `took` 对应 `take / takes / taking / took / taken`。
- **音标补全与发音备用**：优先获取有道音标，失败时保留主词典音标；两者都缺失时，可使用 Datamuse 美式参考音标并标注来源。在线音频缺失或播放失败时尝试浏览器英语朗读。

### 插件内连续查词，不打断阅读与复习

在查词卡、历史、生词本或复习中的释义、例句里选中英文词、短语或句子，即可继续查词或翻译，无需复制到搜索框。

- 支持连续查词和句子翻译，并通过“返回”逐级恢复原内容和滚动位置。
- 复习中保留原题、答案显示状态和评分进度。
- 成功查词同样记入历史，支持收藏；句子翻译不记入历史。暂停网页自动划词后，插件内查词和翻译仍可使用。

### 跨网站历史与生词本

- **完整查询记录**：每次成功查询都会保存，包括重复查询和缓存命中；支持按词筛选、最早／最近排序和逐条删除。
- **一键收藏**：在查词卡或列表中点击星标加入生词本，也可开启“查词直接进入生词本”。
- **分页浏览**：查词历史和生词本每页显示 50 条，各自保留筛选和当前页。删除最后一页的最后一条时，自动返回仍有记录的上一页。
- **手机快捷看词**：点击单词行，即从底部打开释义面板，长释义可在面板内滚动；底部“上一个／下一个”按当前筛选和排序连续切换，跨页无需退出。历史按每条查询记录切换，保留各自的阅读来源。点击“关闭”或面板上方的遮罩返回列表；未切词保留原滚动位置，切过词则定位并高亮最后查看的记录。桌面仍为左右双栏。
- **阅读语境**：可选保存阅读上下文与来源，复习时结合原句回忆。
- **本地共享**：同一浏览器中的不同网站共用词库，不必重复整理。

只有生词本中的词进入复习。取消收藏会删除该词的复习进度，但保留查询历史。

### 根据记忆表现安排复习

- **间隔复习**：使用 FSRS 算法，根据“忘记／困难／记得／轻松”四档反馈调整下次复习时间，而非固定周期提醒。
- **评分说明**：点击“轻松”右侧的 `?`，可查看每档适用的回忆表现及其对下次复习的影响。打开说明不会评分，也不会改变复习计划。
- **学习与重学**：新词和遗忘词通过短间隔步骤巩固。本轮只剩未到期的学习卡时，默认等到到期自动继续，也可主动提前复习；积压时优先复习更可能遗忘的词。
- **可调学习强度**：每日新词默认 20 个，可调整为 0–200 个；目标记得率默认 90%，可调整为 85%–95%。学习日从本地凌晨 4:00 开始，新卡按首次提交评分的时间计入当日额度。
- **反向卡**：可开启“看中文想英文”，无中文时用英文释义。提示和原句会在揭晓前遮住目标词；支持可选拼写核对，正反向进度独立保存。
- **复习仅用缓存**：可在设置 → 复习中开启。出题与揭晓不自动联网补全音标、词形、用法例句或中文释义，仍可手动获取和正常评分。发音可能联网；普通查词不受影响。
- **学习概览**：查看到期任务、今日学习情况、近 30 天真实记得率、难记词和后续安排；没有到期任务时显示下次复习时间。
- **快捷操作与撤销**：复习时可直接选择学习结果，不必先显示释义；空格显示答案，`1`–`4` 可随时评分，`R` 发音，`Ctrl/⌘ + Z` 撤销上一次评分。

完整规则见 [复习规则](docs/REVIEW_RULES.html)（下载后用浏览器打开）。

### 轻量界面，按需启用

- **自由拖动入口**：使用鼠标或触屏拖动 **L**，自动记住位置，并在窗口大小变化时保持可见。
- **深浅色与手机适配**：跟随系统主题。手机上的学习中心以较窄、适度加高的悬浮面板从底部打开，左右和上方保留网页；紧凑的导航、按钮和词列表让一屏显示更多内容，桌面布局不变。点右上角 **×** 或面板外可关闭；打开时不会自动弹出键盘，输入时面板随可见区域调整。
- **查看版号**：手机端在「设置与数据」标题右侧显示当前脚本版号；PC 端仍显示在侧栏 Lexi 标识旁。
- **暂停自动划词**：保留学习中心入口，随时手动查词和复习。
- **原文阅读定位**：网页划词后持续高亮原词或原句，选区失焦或在查词卡内连续查词时仍保留最初位置；单词结果关闭后短暂加强高亮并淡出，句子翻译关闭后立即移除标记。单词标记保留时间可在设置 → 阅读偏好中调整，默认 3 秒，支持 0–300 整数秒，0 秒表示关闭后立即移除。原文滚出屏幕时可点击「回到原文」，不会自动滚动页面；新划词替换旧标记，标记不修改网页正文、不保存到阅读历史中。
- **按页面或域名禁用**：通过查词卡右上角 **⋯** 设置，立即隐藏界面并停止自动查词；规则跨网站、跨标签页共用。
- **集中管理网页**：在“网页管理”中搜索、查看和解除禁用规则；禁用后也可通过 Tampermonkey 的 Lexi 菜单恢复，或手动打开学习中心而不解除禁用。

## 数据备份与迁移

在学习中心 → **设置** 中操作：

- **导出 JSON 备份**：保存词条、完整历史、复习进度与记录、设置和网页禁用规则。
- **导入 JSON 合并**：确认前预览哪些进度会合并重放、哪些因日志不全仅保留较新的记录。重复查询历史会去重，本机设置保留；网页禁用规则需单独勾选并确认导入。
- **导出历史／生词 CSV**：方便使用表格查看和整理，包含已缓存的中文辅助内容；CSV 不能用于完整恢复。

数据不会自动跨浏览器或设备同步。导出和导入使用同一套校验：单个 JSON 文件最多 32 MiB，词条、正向进度、反向进度各最多 10,000 条，查询历史最多 30,000 条。超限时会明确提示，不会下载当前版本无法导入的完整备份；仍可导出 CSV 留存，但 CSV 不能完整恢复。卸载扩展或清理扩展数据前，请先确认完整备份已经成功下载。

包含扩展释义或更多例句的备份可能超过旧版脚本的词条上限；导入或跨设备同步前，请先将两端更新为支持更多例句的脚本。旧备份仍可正常导入。

### 坚果云手动同步

1. 在坚果云创建一个**私有的一级文件夹**（例如 `Lexi`），不要使用共享文件夹。
2. 在坚果云的「账户信息 → 安全选项 → 第三方应用管理」生成应用密码，见[坚果云官方说明](https://help.jianguoyun.com/?p=2064)。不要使用坚果云登录密码。
3. 在 Lexi 的「设置 → 坚果云同步」的两个输入框分别填入坚果云账号邮箱和文件夹名称。密码不在设置面板内填写：点「保存同步配置」后，再在弹窗内填入应用密码。各设备使用同一账号和文件夹。更新脚本后，Tampermonkey 可能提示允许访问 `dav.jianguoyun.com`。
4. 点「立即同步」才会联网，双向合并词条、查词历史、生词本及正反向复习进度。同步也受上述 JSON 大小和条数限制。

**从旧版升级：手机和电脑都更新到 0.6.3 或更高版本。** 原账号及文件夹配置保留；原有 `lexi-sync.json` 仍会读取，不会被覆盖或删除。新版把变更写入独立的同步快照，不依赖 ETag；并发上传的快照会在后续同步时合并。无需手动整理快照：新快照写入成功后，Lexi 只清理已合并的旧快照。旧版看不到新版快照，因此请先更新所有设备。

同步包含历史中已保存的阅读上下文和来源，不包含本机设置、网页禁用规则或应用密码。应用密码仅保存在当前浏览器的 Tampermonkey 存储，不进入备份。本功能按记录合并，不传播删除或撤销：其他设备或云端仍保留的历史、收藏或复习记录可能在下次同步时恢复。「清除同步配置」只移除本机凭据，不删除云端文件或本机词库。同步不能代替独立的 JSON 备份。

## 服务与隐私

- **默认本地保存**：使用 Tampermonkey 存储；只有手动触发坚果云同步才会发送学习数据。不含 Lexi 账号系统、广告或分析上报。
- **查词与翻译需要联网**：[Free Dictionary API](https://dictionaryapi.dev/) 提供英文释义与音频；[有道词典](https://www.youdao.com/) 提供音标、词形、中文释义与用法例句；[Google Translate](https://translate.google.com/)、[Microsoft Translator](https://www.microsoft.com/translator/) 和 [MyMemory](https://mymemory.translated.net/doc/spec.php) 用于句子翻译，单词释义使用 MyMemory 和可关闭的 Google 备用翻译；[Datamuse](https://www.datamuse.com/api/) 提供可关闭的备用参考音标。
- **按需发送查询内容**：词典服务接收查询词，补全词形时可能查询原形；单词英文释义发送给 MyMemory，启用回落时失败后发送给 Google Translate。句子原文先发送给 Google Translate，启用回落时失败后依次发送给微软和 MyMemory。句子翻译请求禁止缓存，但第三方服务是否留存由其政策决定，请勿翻译敏感内容。阅读上下文与来源不会随查词请求发送。在线音频和浏览器朗读也可能联网。
- **服务存在限制**：释义、词形、音标和音频不保证齐全，第三方服务可能限流或不可用；Google 和微软 Edge 使用的非公开无密钥翻译接口不保证可用性，部分网络可能无法访问或接口可能调整；Datamuse 参考音标可能按拼写推测。已有缓存可复用，失败可重试。
