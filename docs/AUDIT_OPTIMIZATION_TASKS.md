审计日期：2026-11-18。范围：复习优先，兼顾备份恢复、历史与生词本。旧版已完成事项见 [0.3.0 复习优化任务](./REVIEW_OPTIMIZATION_TASKS.md)。

**状态：第一至第三阶段已完成；可选项及浏览器交付验证尚未开始。** 每项通过验收后再勾选。

## 第一阶段：恢复测试基线与备份可恢复性

- [x] **A0 · 修正音标回落测试夹具**
  - 审计基线为 142/143 通过。失败用例在历史列表已渲染后才插入 `plopped`，随即点击第一行，实际选中 `alpha`。先让目标词在列表渲染时可见，再按词定位，不放宽请求目标和音标来源断言。
  - **验收：** 用例单独和随全套运行均通过，确认 Datamuse 请求的是 `plopped`，并验证结果标注和入库；如夹具修正后仍失败，再查产品行为。
- [x] **A1 · P1：保证当前版本导出的完整备份可恢复**
  - 现有约 6.18 MiB 的合法 3,000 词条样本可导出，却被 5 MiB 导入限制拒绝。统一字节大小和记录条数的限制。普通备份优先保持现有 JSON 格式；需要分卷时，必须明确说明恢复顺序，并保证每卷符合导入校验，不产生悬空引用。
  - **验收：** 小备份以及超过原 5 MiB 的样本都能通过界面导出并在空白测试词库中恢复；验证词条、重复查询事件、正反向进度与日志不丢失。确认 v1/v2/v3 仍可导入，禁用规则仍单独确认，本机设置仍不被覆盖。不能生成可恢复备份时明确报错，不只提示下载成功。
  - **结果：** 保持 v3 单文件格式，改用紧凑 JSON，导出与导入统一为 32 MiB 并共享记录校验。超限时明确拒绝，不提供分卷。已通过设置页回调与隔离的内存 GM 存储验证小备份、超过原 5 MiB 的备份、旧版导入和超条数拒绝；未在真实 Tampermonkey 验证。

## 第二阶段：修复复习时间与额度

- [x] **A2 · P1：按本地学习日安排长期复习**
  - 长期卡按学习日历推进，保持本地凌晨 4:00 开放；分钟级学习／重学继续按真实经过时间推进，不改 TS-FSRS 上游代码。明确如何处理历史到期数据，不做无提示的全量改写。
  - **验收：** `America/New_York` 在春、秋两次时钟切换前后的长期 2 天间隔均在预期学习日的 04:00 开放；`1m / 10m` 步骤不受时钟切换影响；`Asia/Shanghai` 的 04:00 边界仍正确。概览、卡片队列与生词本显示一致。
- [x] **A3 · P1：用评分提交时间核算每日新卡额度**
  - 将「当前可出题」和「今日已引入」分开。正反向卡仍各计一个新卡名额；关闭反向卡不返还已消耗额度。首次评分提交前重查已保存的进度和当天余额；额度已用完时不写入该评分，也不阻止继续复习旧卡。记录以评分提交时所属学习日为准。
  - **验收：** 03:59:30 揭晓、04:00:15 评分计入新一天；当天学过反向卡后关开设置，余额不变；标签页 A 先用掉最后名额后，标签页 B 的不同新卡评分不超额。另测上限为 0、撤销、保存失败重试和重复评分。完全同时写入仍受 GM 存储限制，不承诺原子性。
- [x] **A4 · 配合 A2/A3 收敛复习会话接口**
  - 让会话模块统一处理开始、揭晓、评分、撤销、陈旧卡及保存结果；界面只发送操作、呈现结果。把 seam 放在会话命令与读写之间，GM 和内存 adapter 使用同一个 interface，并用可控时钟测试。
  - **验收：** 不引入构建步骤，不改动内嵌 TS-FSRS；可脱离 DOM 测试跨日、额度和写入失败。保留键盘、撤销、评分防重、旧记录迁移和一键安装行为。不为拆文件单独做大重构。
  - **验证结果：** Node 测试通过。采用可控时钟和内存存储验证春秋夏令时切换、跨学习日提交、暂停反向卡、另一标签页先用完余额、零额度及保存失败重试；未在真实 Tampermonkey 验证。

## 第三阶段：澄清合并行为与复习交互

- [x] **A5 · P2：让备份合并预览说明实际结果**
  - 区分完整日志可重放与日志不全只能保留较新记录的情况。说明重放使用本机目标记得率，可能改变到期日。稳定事件 ID 和跨设备冲突规则暂不纳入本轮格式变更。
  - **验收：** 用两份完整分叉日志和一份含旧版不完整进度的备份分别验证；预览与导入结果一致，取消确认不写入。
- [x] **A6 · P2：区分到期复习与主动提前学习**
  - 只剩未到期的学习／重学卡时，建议默认显示最近到期时间，提供「现在提前复习」入口，保留现有 20 分钟提前范围。
  - **验收：** 单卡评分后不会立刻自动重出；到期后无需重新开轮即可继续。仍有其他卡时先显示可学卡；主动提前、撤销及离开后的计时器清理正常。
- [x] **A7 · P2：修正反向卡提示与遮盖**
  - 题目标题与实际提示语言一致。原句和释义中出现多次目标词时，揭晓前全部遮盖；没有中文缓存时仍可用英文释义，不阻塞出题。
  - **验收：** 有中文、无中文和原句多次出现目标词的题面均正确；揭晓后恢复原文，拼写核对和正反向独立进度不受影响。
  - **验证结果：** 三项均通过 Node 界面回归测试；未在真实 Tampermonkey 验证。
