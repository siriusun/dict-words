日期：2026-11-12。脚本版本：0.1.1。

## 环境与升级结果

使用用户指定的 ego-browser 技能；实际连接 ego lite，在已安装的 **Tampermonkey 5.5.1** 中新建并保存 Lexi，直接测试真实用户脚本和 GM 存储，未使用 GM 模拟层。测试只使用本机阅读页与一个公开示例网站，没有修改其他用户脚本。

先执行 `ego-browser upgrade`，输出 **`Update failed (error 9).`**。命令进程虽然返回 0，但不能认定升级成功。随后按技能要求重新执行 `ego-browser skill`，当前指南仍为 **v2.2.0**。本轮完成浏览器测试，升级失败单独保留，未强制重装或重启其他浏览器窗口。

默认沙箱无法连接浏览器 bootstrap；本轮在获准的沙箱外执行环境中成功连接，沿用同一个测试空间。测试结束关闭本轮创建的页面与本机临时服务；保留已安装的 Lexi 0.1.1 和本轮的 3 个测试生词、4 条测试历史。

## 测试中修复的问题

1. 长单词标题和发音、收藏操作共用一行，导致 `serendipity` 的末尾单独断行。现在标题占独立一行，音标和操作在下一行。
2. flex 布局中输入框占满宽度，将“查询”和排序文字挤断。现在输入框可收缩，按钮与选择框保持完整文字。
3. 非交互提示条会拦截下方复习按钮的点击。现在提示条不接收指针事件；查词成功后也立即移除对应的“正在查询”状态。
