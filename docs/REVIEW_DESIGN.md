# Lexi 0.2.0 间隔复习

## 成熟程序依据

2026-11-13 核对了以下资料，而非自行拟定固定天数的“遗忘曲线”：

- [Anki：Studying](https://docs.ankiweb.net/manual/studying.md)：先回忆再显示答案，Again / Hard / Good / Easy 四档反馈，按钮显示下次间隔，逾期任务继续保留。
- [Anki：Deck Options](https://docs.ankiweb.net/manual/deck-options.md)：FSRS 以记忆状态安排复习，默认目标保留率 90%；短时学习与遗忘后的重学独立于长期复习；更高保留率会增加负担。Hard 表示答对但吃力，忘记必须选 Again。
- [TS-FSRS](https://github.com/open-spaced-repetition/ts-fsrs)：使用维护中的成熟 FSRS 实现，不另写一套记忆公式。Context7 查询已完成，固定版本的实际类型声明和 UMD 产物也已核对。
- [SuperMemo：SM-2 原始说明](https://super-memory.com/english/ol/sm2.htm)：核对过经典的逐项难度与递增间隔设计；最终使用 FSRS，而非复刻 SM-2。

## 实际行为

只有收藏词进入复习；查询历史不会自动转为学习任务。收藏后立即可学。

| 反馈 | 应如何选择 | 调度行为 |
| --- | --- | --- |
| 忘记 | 想不起来或回答错误 | 新词回到首个学习步骤；已学词进入重学 |
| 困难 | 回答正确，但回忆吃力 | 告知算法这次回忆较困难；学习中重复当前步骤 |
| 记得 | 能正确回忆 | 继续学习步骤，或按更新后的记忆稳定性安排长期复习 |
| 轻松 | 不费力地正确回忆 | 可提前结束初学步骤，并安排更长的复习间隔 |

先显示英文、音标与手动发音，释义在点击“显示释义”后揭示。每个按钮同时显示本次选择对应的下次间隔，悬停或无障碍名称含反馈解释和具体时间。预览与保存调用同一个调度函数，禁用随机 fuzz，避免显示和保存不一致。

调度使用 FSRS-6 默认权重、90% 目标保留率、`1m / 10m` 学习步骤和 `10m` 重学步骤。90% 是模型目标，不是对个人记忆效果的保证；本版不会训练个人参数。实际间隔由模型计算，不固定为某一组天数。

每次成功回忆都保留未来的复习日期，不存在“永久学会并移除”。最长间隔为 365 天，以保留至少年度强化安排。上游在区分反馈间隔时可能超过设定上限 1–2 天，应用适配层统一限制到 365 天，预览与保存都经过此限制。

到期词按到期时间升序排列，逾期不删除；以实际反馈时间安排下一次，不要求补完错过的每一天。每轮最多 20 词，有积压时可继续下一轮。同一词当天重复学习，今日已复习词数仍只计 1。

概览列出最近 6 个未来安排；全部日期可在生词本查看。无到期词时显示最近的下次时间，概览和完成页最多每分钟刷新，到下一个到期时间会提前刷新；切换页面或关闭学习中心会取消计时器。脚本未运行时不计算提醒，不增加系统通知或后台弹窗。

## 数据与升级

沿用原来的 GM 存储键和逐词记录，保留收藏时间、累计复习次数、最近反馈、旧阶段和到期时间。新增 `fsrs` 保存原生 Card 的稳定性、难度、学习状态、学习步骤、间隔、遗忘次数及时间。日期统一保存为毫秒数，进入算法时恢复为 Date，避免 GM/JSON 序列化丢失日期类型。

旧版记录没有逐次反馈日志，不能精确还原完整记忆过程。读取旧进度时，以原到期时间与最近复习时间的差估计稳定性，初始难度为 5；旧“忘记”记录进入重学，其余已复习记录进入长期复习。旧到期时间、累计次数和更新时间保持不变，下一次真实反馈才保存新的 FSRS 状态；不编造过去的遗忘次数。首次估计不代表完成了个体参数拟合。

JSON 备份升级为 v2，导出时同时包含尚未复习的旧记录所对应的迁移状态。v1 备份仍可导入；v2 导入验证数值范围、状态、计数及日期与外层记录的一致性，拒绝无效数据，按原有更新时间规则合并。旧版 Lexi 不接受 v2，以免静默丢弃新记忆字段。CSV 的旧“阶段”改为可读的“学习状态”。

保存失败时不推进当前卡片，保留答案以便重试。重复点击反馈不重复累计。已在另一个标签页复习或取消收藏的当前词会跳过，避免用陈旧按钮覆盖已保存的进度。GM 不提供跨页面原子事务，两个标签页完全同时写同一个词仍遵循原有最后写入规则。

取消收藏仍沿用既有确认流程并删除该词进度；删除单条查询历史不会影响学习状态。

## 内嵌依赖

为保留复制单个用户脚本即可安装、无需构建的方式，在 `lexi.user.js` 的标记区域内嵌 TS-FSRS 5.4.2 UMD 包和完整 MIT 许可证，仅规范化换行和尾随空白，未改动上游算法。没有远程 `@require`，复习计算不向第三方发送单词或反馈。

- 固定版本：5.4.2，使用 FSRS-6 默认模型；选用无运行时依赖、支持独立 UMD 的 5.x 发行版。
- 来源：<https://cdn.jsdelivr.net/npm/ts-fsrs@5.4.2/dist/index.umd.js>
- 原始包大小：72,009 字节。
- 原始包 SHA-256：`59b7444121d0aae5bb969097ed95df38eff4a4f878e459703c63720f6b6a176b`。
- 来源许可证：<https://cdn.jsdelivr.net/npm/ts-fsrs@5.4.2/LICENSE>。

上游算法保持原样，应用逻辑仅负责数据转换、升级、界面、持久化与最长间隔限制。更新算法时应显式核对模型、数据兼容和回归结果，不自动追随 CDN 的 latest。
