# Lexi：划词词典与个人复习库 · 初始设计

> 复习部分已在 0.2.0 升级为成熟 FSRS 调度；当前规则、迁移与来源以 [REVIEW_DESIGN.md](REVIEW_DESIGN.md) 为准。句子翻译已在 0.8.0 增加，当前功能以 [README.md](../README.md) 为准。下方记录的是初版设计。

版本：0.1 / 2026-11-12。目标平台：桌面 Chrome、Edge、Firefox + Tampermonkey。

## 1. 产品定位与已确认决策

在阅读网页时快速理解一个英文单词，并把值得记住的词带入复习。主要界面为中文，保留英文原始释义。

用户原先提出 localStorage；沟通后已明确选择 **跨网站统一历史，允许使用油猴 GM 本地存储**。因此词库不按网站域名分散，不使用页面 localStorage 保存学习数据，不提供账号或服务器同步。导出文件是跨设备迁移与备份的途径。

本轮先保存本设计，再交付单文件脚本和自动检查；设计并不代表已通过真实浏览器验收。

## 2. 最小完整体验

1. 鼠标选中一个英文单词，约 220 ms 后自动出现查词卡，不必再点图标。
2. 卡片显示单词、音标、词性、英文释义、接口提供的例句、发音按钮、收藏按钮。
3. 成功查词自动记录历史，包括缓存命中；重复查询也保留独立记录。历史默认最近在上，可切换最早在上。
4. 用户收藏后加入生词本，立即可复习。普通查询不会自动变成复习任务。
5. 在学习中心查看历史、生词与复习，按单词过滤，手动查询，导出或恢复数据。

不支持整句翻译、PDF 阅读器内部文本、封闭 Shadow DOM 和跨源 iframe 内的选词。普通 HTML 内可选文字优先；输入框、密码框和可编辑区不触发。

## 3. 查词细节

| 情况 | 行为 |
| --- | --- |
| 英文单词 | 忽略大小写，去掉外围引号和常见标点，保留内部连字符与撇号 |
| 多个词、中文、数字、超过 64 字符 | 不自动请求；手动输入时提示只支持单个英文词 |
| 变形、专有名词、缩写 | 按原词查询，不伪造词形还原；无结果时建议手动修改 |
| 连续划 A、B | 取消旧请求，只展示最后一次查询，旧结果不写历史 |
| 重复点历史 / 复习卡 | 查看已保存释义，不新增查词事件 |
| 词典无音标、例句或音频 | 对应项目自然省略；音频缺失时尝试浏览器英语朗读 |
| 发音 | 用户点击后播放；不自动出声、不承诺英美双音源 |
| 网络错误 | 显示可重试状态；已有缓存可继续使用 |
| 缓存 | 7 天内直接使用；过期尝试更新，失败回退旧释义并明确提示 |

来源上下文默认不记录。用户可开启“保存阅读上下文”，只保存附近短句、页面标题和去掉 query/hash 的来源 URL；上下文不发往查词和翻译接口。

## 4. 服务选择与边界

### 主词典：Free Dictionary API

- 官网：https://dictionaryapi.dev/
- 查询：`GET https://api.dictionaryapi.dev/api/v2/entries/en/{word}`。
- 预期使用字段：`word`、`phonetics`、`meanings[].partOfSpeech`、`definitions`、`example`、`sourceUrls`、`license`。
- 按公开免密接口设计；不内置密钥，不抓取有道、牛津等网页。
- 缺失字段可接受，必须保留释义来源和接口返回的许可链接。

### 中文辅助：MyMemory，自动补全并缓存（0.1.2 调整）

- 文档：https://mymemory.translated.net/doc/spec.php
- 请求：`GET https://api.mymemory.translated.net/get?q={firstDefinition}&langpair=en|zh-CN`。
- 查词或打开词条后自动补全最多 6 条英文释义，包含词性和编号，每段请求不超过 480 UTF-8 字节；不发送网页原文。
- 标记“机器翻译”，不是权威双语词典。请求失败或额度不足时保留英文释义，可重试；成功结果本地缓存。
- 多条中文成功后保存词库，复习、CSV 和 JSON 备份均可使用；旧单条翻译在打开词条时补全。对应英文释义变化时重新获取。失败可重试，不绕过限流，不调用收费接口。

### 本轮核对状态

Context7 按用户要求尝试沙箱外调用，被环境执行策略拒绝；ego-browser 启动亦因无法连接 bootstrap 失败。随后使用普通 HTTP 请求获取了三方官方文档，并实际调用两项服务：

| 核对项 | 2026-11-12 结果 |
| --- | --- |
| Free Dictionary 官方文档 | HTTP 200，确认公开查询路径和 `phonetics` / `meanings` 结构 |
| 查询 `serendipity` | HTTP 200，成功归一化，含释义、音标和允许域名的音频地址 |
| MyMemory 官方文档 | HTTP 200，确认 `q` 最多 500 UTF-8 字节、`langpair` 用 `\|` 分隔；实现使用更保守的 480 字节上限 |
| 翻译 `A pleasant surprise.` | HTTP 200，业务状态 200，返回非空翻译 |
| Tampermonkey 请求与存储文档 | HTTP 200，确认同步 GM 存储、跨标签监听、请求回调和取消接口；`anonymous` 会强制 fetch 模式，因此额外用 JS 计时器保证超时 |

文档依据：[请求接口](https://www.tampermonkey.net/documentation.php?q=GM_xmlhttpRequest)、[存储接口](https://www.tampermonkey.net/documentation.php?q=GM_values)、上方词典与翻译文档。本轮验证属于主机 HTTP 请求，**不代表油猴实装、音频播放、浏览器网络或视觉验收**。不据此承诺未来可用性、固定额度或任意地区网络可达性。

## 5. 学习闭环

历史是“查过什么”，生词本是“准备学什么”，复习是“下一次什么时候学”。三者分开。

- 收藏：建立复习记录，首次立即到期；取消收藏同时移除该词复习进度，操作前确认。
- 复习正面：单词、音标、手动发音；点击“显示释义”后显示答案和反馈按钮。
- 忘记：阶段归零，10 分钟后再见。
- 模糊：阶段不变，1 天后再见。
- 记住了：依次安排 1、3、7、14、30、60 天，达到 60 天后保持该间隔。
- 每轮最多 20 个到期词，按到期时间排序。轮内不立即重复；忘记的词会在到期后的新一轮出现。
- 显示到期数量、总收藏词数，以及今天复习过的不同词数。不会把同词多次复习误算成多个词。

这是透明、便于理解的初版间隔规则，不宣称实现 SM-2 / FSRS，也不承诺记忆效果。暂不做拼写测验、学习排行榜、签到、通知和 AI 助教。

## 6. 视觉与交互

方向：纸张色背景、墨色正文、森林绿强调色、低饱和灰色分隔线；深色跟随系统。单词标题采用 Georgia 等系统衬线字体，中文及控件采用系统无衬线字体，不下载字体和图片。

### 查词卡

宽约 380 px，贴近划词位置，按视口边界调整；圆角 18 px、细边框与柔和阴影。布局从上到下：

```text
LEXI · 英语词典                           ×

serendipity                          发音
/ˌserənˈdɪpəti/                      收藏

noun
The occurrence of events by chance ...
例句（接口有提供时）

中文辅助释义

Free Dictionary / 许可信息       学习中心 ↗
```

释义最多保留 5 个词性分组，每组 3 条，避免长词条淹没卡片。长内容内部滚动。保存上下文可展开显示，错误在原位置说明，不用阻断式弹窗报告普通网络故障。

### 学习中心

独立居中面板，桌面最大宽约 1060 px，高度不超过视口 90%；窄屏收拢布局。左侧为品牌和“历史 / 生词本 / 复习 / 设置”，右侧有常驻手动查词框。

历史和生词页使用列表与详情两列；列表保留时间、词形、收藏或到期状态。当前项用淡绿背景与边线标记。复习页使用单张大卡，反馈按钮保持稳定位置。

右下角低干扰“L”入口，可从油猴菜单打开。设置可暂停自动划词；暂停后仍能手动查词。关闭面板不重置学习进度。

### 无障碍

所有交互使用原生按钮与表单控件；提供可见焦点和图标标签。Esc 关闭，学习中心限制 Tab 焦点在对话框内，关闭后回到先前焦点。查词卡为非模态区域，不抢走阅读焦点。尊重减少动态效果设置，颜色不是唯一状态提示。

## 7. 数据结构与导出

使用命名空间 `lexi:v1:`。词条、历史事件、收藏进度分别保存，避免每次查词覆盖整份历史；历史事件用随机 UUID，跨标签查询可追加独立事件。相同词的释义缓存和学习进度采用最后写入者生效，不提供跨标签事务锁。

| 记录 | 内容 |
| --- | --- |
| `word:{word}` | 标准词形、音标、可用音频、词性释义、出处、许可、缓存时间、可选中文辅助 |
| `event:{uuid}` | 词形、查询时间、可选阅读上下文和来源 |
| `study:{word}` | 收藏时间、阶段、到期时间、累计复习次数、最近复习日期与反馈 |
| `settings` | 自动划词、是否保存阅读上下文 |
| `revision` | 跨标签刷新通知；不作为历史数据 |

- **JSON 备份**：版本号、导出时间、词条、完整事件、生词进度、设置。可用于恢复与迁移。
- **历史 CSV**：每次查询一行，按最早到最新输出，包含时间、词形、英文首义、中文辅助和可选来源。
- **生词 CSV**：每词一行，包含释义、中文、阶段与到期时间，方便表格或制卡工具使用。
- CSV 使用 UTF-8 BOM、双引号转义，并防范表格公式注入。
- JSON 导入先校验版本、大小（最大 5 MiB）、字段和引用，再预览数量并确认；按事件 ID 去重、按词形合并，采用更新时间较新的词条与进度，保留当前设置。
- 导入不执行 HTML、不访问导入文件中的地址。没有数据时提供明确空状态。
- 清空历史只删除查询事件；删除全部数据另设操作，必须输入确认文字，提示先导出备份。

## 8. 隐私、安全与性能

词库本地存于扩展管理的 GM 存储，不主动上传词库。第三方只接收当前查询词，或用户主动请求翻译的一条词典释义；在线音频和浏览器朗读可能使用外部服务。

仅匹配 HTTP/HTTPS 顶层页面。Shadow DOM 隔离样式；它不是安全隔离边界，不应在不信任的页面操作敏感学习资料。词条和导入内容以文本节点渲染，不拼接为 HTML。接口仅允许两个明确域名，音频限定已知 HTTPS 域名；其他音源回退浏览器朗读。

请求超时 10 秒；不轮询、不监听每次鼠标移动、不全页面扫描；不把音频二进制存进词库。浮层关闭取消未完成查询。接口失败不清空数据，导入失败不谎报完成。扩展停用、卸载、清理数据或更换浏览器会影响可用数据，应定期导出备份。
